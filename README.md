# PDF Slicer — 스캔 답안지 자동 분할기

학급 전체 답안지를 한 번에 스캔한 PDF를 **학생 번호별 파일**로 자동 분할합니다.
브라우저에서만 동작하며, PDF는 서버로 전송되지 않습니다.

**바로 사용:** https://pdfslicerweb.vercel.app

![screenshot](제목%20없음.png)

## 이런 때 씁니다

- 수행평가·지필평가 답안지를 복합기로 한 번에 스캔해서 `전체.pdf` 하나로 받았을 때
- 학생별로 나눠서 저장하거나, 개별 피드백·업로드용 파일이 필요할 때

## 사용 방법

1. **원본 PDF** 선택 (또는 오른쪽 미리보기 영역에 끌어다 놓기)
2. **파일명 설정** — 학년반 앞자리(예: `109`)와 접미어(예: `_수학`) 입력
   → `10901_수학.pdf`, `10902_수학.pdf`… 순으로 생성
3. **학생 1명당 페이지 수** 입력 (기본 2쪽)
4. **결번** — 결석 등으로 빠진 번호 입력 (예: `3, 7, 15`) → 건너뛰고 다음 번호로 이어짐
5. **페이지 수 예외** — 특정 학생만 페이지가 다를 때 `번호:페이지수`로 입력 (예: `5:4, 12:6`)
6. 아래 **분할 계획** 표에서 각 파일이 몇 쪽을 가져가는지 확인
7. **일괄 분할 → ZIP 저장** 클릭 → `109_수학_분할.zip` 다운로드

입력을 바꿀 때마다 분할 계획이 즉시 갱신되고, 페이지 수가 맞지 않으면 경고가 표시됩니다.

## 특징

- 설치 없음 — `index.html` 하나로 동작, 로컬에서 열어도 됨
- 업로드 없음 — 모든 처리는 브라우저 안에서 (pdf.js · pdf-lib · JSZip)
- 미리보기로 페이지를 넘겨가며 번호·페이지 수 확인 가능
- 다크 모드 지원

## 로컬에서 쓰기

`index.html`을 받아 더블클릭하면 됩니다. 라이브러리는 CDN에서 불러오므로 인터넷 연결은 필요합니다.
